# 블록체인
## 블록체인이란 무엇인가?
```
블록체인은 데이터를 블록 단위로 묶어 체인처럼 연결한 분산 원장기술이다. 블록에는 트랜젝션, 이전 블록 해시 ,생성 시간등의 정보가 포함이된다.
```
### 핵심 특징
```
1.불변성:한번 기록된 정보는 변경이 매우 어렵게 된다. 불가능한건 아니다. 블록의 해시는 이전 해시블록에 의존을한다. 따라서 하나의 블록을 수정하면 전체 체인을 수정해야한다.
2.투명성:퍼블릭 블록체인의 경우 누구나 트랜젝션의 내역을 조회 할수 있다. 따라서 신뢰성이 확보된다.
3.보안성:SHA-256등 해시 함수와 디지털 서명 기반의 암호화 기술로 무결성과 인증을 보장합니다.
4.힙의 알고리즘(Consensus):PoW,PoS,PBFT등 다양한 방식으로 분산 노드간 트랜잭션의 *정합성을 보장한다.

**정합성 : 여러 데이터나 요소들 사이에 모순 없이 일관된 상태를 유지하는 것
데이터의 정합성 :여러요청이 동시에 처리될때 데이터가 의도치 않게 변경되지않도록 보장 하기 위함.
```

### 기술
```
1.Merkle Tree
2.Nonce + 해시 퍼즐 (Proof-of-Work)
3.P2P 네트워크 
```

# 스마트 컨트랙트

## 스마트 컨트랜트란 무엇인가?
```
스마트 컨트랙트는 조건이 충족되면 자동으로 실행되는 코드로, 블록체인 위에 배포되는 자율적 계약입니다. 중앙 제어 없이 신뢰를 코드로 대체합니다.
```

### 핵심 특징
```
1.자동화 : 중개인 없이 프로세스를 실행
2.신뢰성 : 계약조건이 블록체인에 기인 되기때문에 위변조가 불가능하다.
3.비용 절감 : 법적 계약이나 중재자 없이도 계약 이행 가능
```

### 알아 두어야할 주의점

```
1. 오류 수정이 불가능하다.
2. 복잡한 계약 모델에는 미흡 외부 데이터 연동이 필요하다.
3. Gas 비용 문제 복잡한 연산일수록 비용 증가(이더리움)
```

### 기술
```
1.Solidity
2.Rust(Solana용)
3.Cairo
4.Vyper
```


# 탈중앙화

## 탈중앙화 정의
```
중앙 관리자 없이 시스템을 다수의 노드(참여자)가 공동으로 운영·관리하는 구조입니다. 권한 분산, 검열 저항성, 신뢰의 분산이라는 개념으로 연결됩니다.
```
### 탈중앙화 층위
```
1. 네트워크 탈 중앙화 : 노드가 물리적으로 분산되어 있어 특정 국가나 기관이 통제 불가
2. 데이터 탈 중앙화 : 원장이 중앙서버가 아닌 여러 노드에 복제되어 저장
3. 권한 탈 중앙화 : 운영·개발·의사결정 권한을 커뮤니티로 분산
```

### 핵심 기능

```
1. 검열 저항성
2. 중앙화 실패 방지
3. 참여적 거버넌스
```
