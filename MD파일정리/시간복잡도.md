# 얼고리즘

## 시간복잡도

- 빅 - 오메가 : 최선일 때(best case)의 연산 횟수를 나타낸 표기법
- 빅 - 세타 : 보통일 때(average case)의 연산 횟수를 나타낸 표기법
- 빅 - 오 : 최악일 때 (worst case)의 연산 횟수를 나타낸 표기법 

1. **코딩테스트** 에선 빅 오 표기법으로 생각하는것이 제일 좋다.
2. 연산 횟수의 기준은 **1초에 1억번** 연산 을 하는것으로 생각한다.

### BufferWriter

```
ex) 시간 제한이 2초 인 문제를 해결하려면 연산 횟수가 2억번 이하의 연산 횟수로 문제를 해결해야한다. 

문제 정의 순서 : 
1. 시간 제한을 생각하고 연산 횟수를 파악한다.
2. 알고리즘의 연산 횟수를 파악한다. 예시 버블 정렬-> n^^2 : 부적합 ||| 병합 정렬 -> nlog(n) : 적합
3. 코드 개선을 위한 로직을 정리하려면 시간복잡도를 통한 속도 개선이 필수다.
```

### 디버깅

- 정의 : 논리 오류를 찾아 바로 잡는 과정
- 디버깅 하는법 : 코드 디버깅하고자 하는 줄에 중단점(breakpoint)을 설정

### 나눗셈
- 나눗셈의 분배법칙은 산수와 다르다. 나눗셈 자체의 분배법칙은 컴퓨터 연산에서는 다르게 들어간다.
